# Инструкции для ИИ-помощников

Прочитайте [правила владельца](docs/OWNER_RULES.md) и [инструкции проекта](CLAUDE.md). Соблюдайте также инструкции для затронутой части репозитория.

Для содержательных решений применяйте раздел «Библиотека FPF» из `CLAUDE.md` и сверяйтесь с официальным [USING-FPF.md](https://github.com/ailev/FPF/blob/HEAD/USING-FPF.md). При обычных правках следуйте инструкциям проекта.

FPF служит справочной методологией. Редактируйте код и запускайте разрешённые проверки в рамках обычного рабочего процесса проекта.
