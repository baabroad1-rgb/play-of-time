# Play of Time

Тренажёр чувства времени: секундомер, в котором надо остановиться ровно на **3.000 с**.
За точность начисляются Serenity Coins, прогресс идёт по системе квестов.

Сайт: [playoftime.online](https://playoftime.online) · Владелец продукта: Alexander Belyshkin

## Две реализации одного продукта

**Нативная Android-версия — фронтир.** Веб её догоняет. Это значит:

* Поведение определяет Kotlin в `android/app/src/`. Если веб и нативка расходятся — **прав Kotlin**.
* Порядок авторитета: `android/app/src/**/*.kt` → `docs/webapp_handoff.md` → `webapp/app.js`.
  Спека написана руками и отстаёт; код — нет.
* Карта «какой файл определяет какое поведение» — в `webapp/README.md`.
* Статус отставания веба ведётся в `docs/PARITY_AUDIT.md`. Это не черновик, а рабочий трекер.

## Что изменилось с переездом на git (26 сентября 2026)

До этого истории версий не было, и её заменяли руками. Три механизма больше не нужны:

| Было | Стало |
|---|---|
| Два `CLAUDE.md`, которые требовалось держать идентичными | Один, `android/CLAUDE.md`. Копии всё равно разошлись |
| `webapp/reference/native-src/*.kt` — ручное зеркало нативного кода | Удалено. Живой код в том же репозитории, читать напрямую |
| Снапшоты проекта в `handover/code/`, `all_source.txt`, `.rar`/`.zip` | История git |

Из этого следует правило: **не копируй файлы, чтобы «сохранить как было»** — для этого есть коммит.
Копия неизбежно расходится с оригиналом молча, и все три случая выше это подтвердили.

Что пока осталось как было: в `webapp/` лежат 14 версий `app.2026xxxx.js` и 9 версий
`styles.*.css` — ручная история веба. Живая версия та, что подключена в `index.html`
(сейчас `app.20260925c.js`). Сворачивать это в один `app.js` надо отдельно и аккуратно,
потому что имя файла участвует в деплое.

## Сборка и запуск

**Android.** JDK 17+ (разработка на Temurin 21) и Android SDK.
`local.properties` в репозиторий не входит — на новой машине задать `ANDROID_HOME`
либо создать `android/local.properties` со строкой `sdk.dir=<путь к Android SDK>`.

```bash
cd android
./gradlew assembleDebug     # или assembleRelease
```

APK появится в `android/app/build/outputs/apk/`. Версия задаётся в
`android/app/version.properties`, имя APK = версия **до** автобампа.
Debug тоже собирается через R8, поэтому первая сборка после clean — около 9 минут.

**Веб.** Сборки нет, чистая статика:

```bash
cd webapp
python -m http.server 8000
```

## Чего в репозитории нет и почему

| Не хранится | Где живёт |
|---|---|
| `keystore.jks` — ключ подписи приложения | Только локально. Потеря = невозможность обновлять приложение в Google Play, поэтому нужна отдельная резервная копия вне ноутбука |
| `local.properties`, `.env`, пароли БД | Локально; для прода — в `pot-secrets/config.php` вне папки сайта или в переменных окружения (см. `webapp/api/config.php`) |
| Собранные APK | GitHub Releases |
| `build/`, `.gradle/`, `.idea/` | Генерируются сборкой |
