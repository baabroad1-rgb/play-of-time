# Как выложить новую версию для самообновления (Alex 2026-09-22, финальная версия)

⚠️ Это временная заплатка для сайдлоада, удаляется целиком при выходе в
Google Play (см. doc-comment в `core/update/UpdateApi.kt`).

**Никакого JSON. Только сам APK под своим настоящим именем.**

Приложение проверяет версию через уже существующий `api/latest_apk.php`
(его написала веб-сессия для ссылки "download app apk" на сайте — теперь
им же пользуется и самообновление в приложении, один и тот же файл-источник
правды для обоих).

## После каждого нового релиза

1. Взять собранный APK — он уже называется как надо, например
   `play-of-time-v13.97.apk` (имя формирует сама сборка).
2. Загрузить его в папку `downloads/` **под своим настоящим именем, без
   переименования**.
3. Старую версию можно удалить, а можно и оставить — `latest_apk.php` сам
   найдёт самый свежий по дате изменения файл среди всех `.apk` в папке.

Больше ничего — ни JSON, ни отдельного файла с номером версии.

## Как это работает

- **Сайт** (`index.html`, кнопка "download app apk") уже ссылается на
  `api/latest_apk.php` — он находит единственный (или самый свежий) `.apk`
  в `downloads/` и отдаёт его как есть, с `Content-Disposition: attachment;
  filename="play-of-time-vX.Y.apk"`.
- **Приложение** (`core/update/UpdateApi.kt`) при каждом запуске делает
  HEAD-запрос на тот же `api/latest_apk.php`, читает настоящее имя файла из
  `Content-Disposition`, вытаскивает из него версию (X.Y) и сравнивает со
  своей. Если на сервере версия больше — показывает кнопку обновления, тап
  скачивает apk с того же URL.

## Проверка после загрузки

```bash
curl -sI https://playoftime.online/api/latest_apk.php | grep -i "content-disposition\|content-length"
```
Должно показать `Content-Disposition: attachment; filename="play-of-time-vX.Y.apk"`
с актуальным именем только что загруженного файла.

## Известное ограничение

Best-effort, как и синхронизация лидерборда — если сеть недоступна или
эндпоинт не отвечает, кнопка обновления просто не появляется, без ошибок
для игрока. Проверка идёт один раз при каждом запуске, без кеша на диске.
