## 3. Переезд на новый пакет: когда он закончится

Вопрос Алекса «а когда же переезд закончится» сделан измеримым.

Приложения шлют свою версию в `sync.php`, она копится в колонке
`app_version`. Сводка (только агрегаты, без имён) — `api/app_versions.php`,
удобный отчёт — workflow `check-migration.yml`.

**Условие конца:** в группах `14.9x` и «версия не сообщена» не осталось
игроков, активных за последнюю неделю.

Снимок на 28.09.2026: `15.05 native 1`, `14.93 native 1`,
`не сообщ. native 27 (10 активных за неделю)`, `не сообщ. web 20`.
«Не сообщено» — это в основном старые сборки, которые про телеметрию не
знают; они и есть те, кого ждём.

**Что сделать, когда закончится** (список из записки 26.09, он в силе):
убрать мостовую из `downloads/`, перенести туда новое приложение, вернуть
`latest_apk.php` в `core/update/UpdateApi.kt`, поменять `dest_dir` по
умолчанию в `build-apk.yml`. Пока не сделано — `next_apk.php` на пустую
папку отвечает 404, и приложение молча считает, что обновлений нет.

## 4. Автоматика GitHub

| Файл | Когда | Что делает |
|---|---|---|
| `deploy-web.yml` | правки `webapp/` в main | заливает сайт по FTPS |
| `build-apk.yml` | правки `android/` в main | собирает APK, кладёт на хостинг, заводит релиз, бампает версию |
| `check-build.yml` | пуш в любую ветку кроме main | только компилирует |
| `commit-log.yml` | любое изменение в main | пересобирает `docs/COMMIT_LOG.md` |
| `fix-db-config.yml` | вручную | собирает `api/config.php` на сервере из секретов |
| `check-api.yml` | вручную | опрашивает эндпоинты, **сверяет выложенный `report.html` с репозиторием побайтно**, печатает, какой APK лежит по каждому адресу |
| `check-migration.yml` | вручную | разбивка игроков по версиям, активность за неделю |
| `check-lucky.yml` | вручную | разовая диагностика Lucky Index |

Секреты и три классические грабли (секрет с именем `PATH`, неявный ключ
подписи, выкладка затирает `api/config.php`) — в `HANDOFF_2026-09-26.md`,
там всё ещё точно.

**Два workflow могут пушить в main одновременно** (автобамп версии и журнал
коммитов). Оба обёрнуты в цикл «пуш → не вышло → `pull --rebase` → ещё раз»,
три попытки. Если добавляешь третий пишущий workflow — делай так же, иначе
он будет молча терять свою работу.

**Из контейнера сессии сайт не виден** — прокси режет `playoftime.online`.
Поэтому проверка «что реально лежит на сервере» делается не `curl`, а
запуском `check-api.yml`.

## 5. Страница отчёта с мордами

Самая живая часть последней недели. Подробности — `webapp/CLAUDE.md`,
раздел «Страница отчёта».

Коротко: две морды Чернова (текущий период и период сравнения) лежат друг
на друге в общем кадре, граница между ними двигается пальцем — «шторка».
Ручка слева = «сегодня», тянешь вправо — выходит период сравнения. Под
лицом ОДНА кнопка периода, она показывает период того лица, что сейчас в
кадре, и переключается на середине. Тап по ней открывает выбор периода для
той стороны, что видно.

**Правило, купленное дорого:** страницу нельзя править вслепую. До 27.09 я
менял `report.html`, ни разу её не отрисовав, и это стоило нескольких
кругов «не видишь что лицо криво отрисовано». Теперь перед каждой выкладкой
поднимается локальный стенд и страница снимается в браузере. Как — в
`webapp/CLAUDE.md`.

## 6. Как работать с Алексом

Он единственный владелец продукта, работает с телефона, пишет по-русски,
коротко и жёстко. Нарушение этих правил стоит времени обоих.

- **Один вопрос за раз.** Список вопросов он не читает.
- **Язык функциональный.** Без «отлично!», без пересказа того, что он и так
  знает, без списка вариантов, которые ты не собираешься делать. Сказать,
  что сделано, что решил по ходу и чего не знаешь.
- **Визуальные изменения — сначала превью, потом код.** «Только ты может
  сразу не курочь кода а покажи превью, согласуем и тогда уже».
- **Не выдумывать.** Если чего-то не проверял — так и сказать. «Не
  выдумывай» было сказано ровно за домысел вместо проверки.
- **Пароли ему не показывать**, в логи CI не печатать, `keystore.jks` не
  коммитить, `api/config.php` держать исключённым из выкладки.
- **Решения записывать.** Он требует журнал: почему так сделали. Место —
  `docs/CHANGELOG.md` и подробные сообщения коммитов.
- Ругань в его сообщениях — это темп, а не отказ от работы. Реагировать на
  содержание.
