  `#A78BFA`.
- Вместо «You» писать имя игрока, но только если он ввёл его сам

## 3. Почему сделано так (не очевидно из кода)

- **Fly Doppelgänger** — отдельная база `doppelganger.db` с той же схемой
  `TimeDatabase`. Он делает ровно одну попытку на каждую попытку игрока
  («lockstep»). В его попытках поле `deflection` хранит id попытки игрока:
  это курсор досинхронизации (`RivalEngine.syncLocked`). Его квест не
  зависит от квеста игрока.
- **«Муха»** — `MicroPlayer.kt`, обучение по модели грибовидного тела:
  2000 клеток Кеньона, fanIn 6, активны верхние 5 %, 7 вариантов шага
  поправки, контрфактический дофамин. Это заменило фильтр Калмана, чтобы
  ИИ «учился» буквально. Алекс просил указывать авторов модели, но не
  писать, что идея его.
- **График прохождения**: значение точки = индекс квеста × 100 + номер
  подквеста. Подквест — это ступень поблажки по допуску ±t, записанному в
  попытке (`TryDatabaseModel.toleranceMs`). Поблажка по числу попыток N в
  попытках не хранится, поэтому на графике её нет. Квест попытки берётся
  из её сессии: при смене квеста приложение начинает новую сессию, и у
  игрока, и у Fly.
- **Error distribution** (Analytics, график по умолчанию с 15.11):
  - края — P3/P97 знаковых ошибок, как у удалённой карточки Range of
    deviations;
  - ширина столбика не меньше шага касаний (`getTouchCellMs`), иначе
    получается «гребёнка»;
  - зелёный только центральный столбик, по положению, а не по победам.
- **Выкладка APK** (`build-apk.yml`, шаг «Положить APK на хостинг»):
  - сначала SFTP (`infousil.beget.tech`, тот же аккаунт), FTP — запасной;
  - файл заливается как `NAME.part` с докачкой и переименовывается, только
    когда размер совпал байт в байт;
  - старые APK удаляются последними.

  До этого были две аварии: 404, а потом обрезанный APK.

## 4. Грабли

- Сборки на GitHub иногда по 15–30 минут стоят в очереди. Группа
  `build-apk` при новом push отменяет ожидающую сборку, а не ту, что уже
  идёт. Когда push и ручной запуск сделаны одновременно, обе сборки
  могут лить на сервер параллельно.
- Шаг автобампа версии падает, если в `main` одновременно пишет другой
  workflow. APK при этом уже собран: смотри шаг, а не общий статус.
- Если при переименовании веб-файлов (`app.YYYYMMDDx.js`) сделать
  `git mv`, пропадёт старая версия, на которую ещё ссылаются кэши.
  Копировать, а не переносить: так 11.11 потеряли `app.20261108b.js`.
- Обращаться к прод-базе напрямую и читать пароли из
  `webapp/api/config.php` нельзя. Исследовательские эндпоинты
  (`research_*.php`) отключены, отдают 410 по решению Алекса.
