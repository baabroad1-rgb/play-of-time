# Передача: измерительная версия (measurement/) — 19.11.2026

Здесь только то, чего нет в коде и в `docs/CHANGELOG.md`: договорённости с
Алексом, его отказы, незаконченное и подводные камни. Что и когда менялось,
смотри в CHANGELOG (записи «Measurement: …» с 14.10.2026).

## 1. Договорённости и решения Алекса

1. Измерительная версия — **копия** движка игры, а не подключение к нему. Игру
   (`webapp/`) и приложение (`android/`) не трогать. Квестов нет, уровень
   выбирается в Settings.
2. Выкладка measurement и выкладка игры — **два независимых процесса**
   (слова Алекса). Отдельный workflow, своя папка на сервере, свои таблицы в
   базе. Связывать их нельзя.
3. Late avg и Early avg (в Ranks и в карточке после замера) считаются **только
   по промахам**. Попадание, у которого миллисекунды чуть уходят от 3.000, в
   средние не входит. Geom. mean Early/Late в Analytics считается так же,
   Absolute — по всем попыткам.
4. Попытки в минуту — только время, пока **главный экран открыт и виден**.
   Ranks, Analytics, Settings, свёрнутый браузер и лендинг в зачёт не идут.
5. Кнопки уровня — только числа (3.0 / 3.00 / 3.000), три в ряд, без подписей.
6. Переключатель Salute & result sounds убран, звук всегда выключен.
   Поэтому hooray на каждое попадание, который есть в коде, на деле молчит.
7. Ranks: уровни на самом верху → сообщение «You are not in the table yet…»
   с кнопкой Play → поле имени и Save (заблокированы, пока игрока нет в таблице
   этого уровня) → таблица.
8. Analytics: никаких фильтров периода. Только метка Session и выпадающий
   список «дата · номер сессии за день · время начала».

## 2. Что Алекс отклонил — не возвращать

- **Номер версии 2.001** в Settings и на лендинге. Алекс сначала попросил, потом
  велел игнорировать. Сделанное откатили (коммит 4c1170b). Без новой просьбы не
  добавлять.
- **Строка с прочерками** вместо своей строки в Ranks: «нахуя мне прочерки».
  Вместо неё — понятное сообщение.
- **Автопереход на главный экран после Save** и подсказка под секундомером:
  сообщение должно быть на экране Ranks.
- Лишние объяснения и таблицы перед вопросом. Вопрос Алексу — одной строкой, на
  который можно ответить «да» или «нет».

## 3. Чего сайт сделать не может (Алекс спрашивал)

- Всплывающую подсказку браузера про выход из полноэкранного режима сайт убрать
  не может: её показывает сам браузер. Совсем без строк браузера и без неё —
  только запуск с иконки на домашнем экране (`manifest.webmanifest`,
  display: fullscreen).
- На iPhone Safari полноэкранного режима для страниц нет; там кнопка Start
  measurement просто открывает `play.html`.

## 4. Незакончено и известные хвосты

- **Старые замеры на сервере** (`m_measurements`) с `per_minute`, посчитанным
  по старому правилу (время от первого RUN до последнего STOP), не пересчитаны.
  Сессии, начатые до исправления 14.10, несут раздутое `activeTimeMs`. Алекс
  видел «0,6 попыток в минуту» именно из-за этого. Миграции нет.
- Жалоба «программа открылась, ни клювика, на странице ничего не видно»
  пришла в одном сообщении с отменённой просьбой про 2.001, и Алекс велел
  игнорировать всё с того места. **Не расследовалась.** Если повторится,
  разбирать с нуля.
- Внутри `play.*.js` остался недостижимый код игры: квесты, cheer-ups, салют,
  старый Analytics, старый лидерборд. Его оставили, чтобы не ломать
  копию; вычищать только аккуратно и с проверкой в браузере.
- Имена игроков на сервере могут повторяться, проверки уникальности нет.
- Ссылка на claude.ai-артефакт (`claude.ai/artifact/TzsLuJKVkBQFKbap3Beago`) —
  старая тестовая сборка, не обновляется. Рабочий адрес —
  https://playoftime.online/measurement/

## 5. Выкладка и проверка — грабли

- Любая правка JS или CSS — **новое имя файла** (`play.YYYYMMDDx.js`,
  `styles.YYYYMMDDx.css`) и правка `play.html`. `index.html` и `play.html` не
  кэшируются (`measurement/.htaccess`).
- `deploy-measurement.yml` срабатывает на `measurement/**` в main, после
  заливки скачивает страницы с сайта, сравнивает с репозиторием и дёргает
  `api/leaderboard.php`. Зелёный прогон = на сайте то же, что в main.
- FTP-Deploy-Action **сам удаляет** на сервере файлы, удалённые из репозитория
  (проверено 12.11.2026). Запись от 14.10 о том, что старые сборки копятся, была
  неверной. `cleanup-measurement.yml` (ручной) оставлен на всякий случай.
- API `measurement/api/*.php` берёт доступ к базе из серверного
  `/api/config.php` игры. Таблицы `m_players` и `m_measurements` создаются сами
  при первом запросе. Игровые таблицы этот API не читает и не пишет.
- Сайт `playoftime.online` из контейнера Claude не открывается (прокси). Всё
  «как на сервере» проверяется через workflow.
- Локальная проверка: `POT_TEST_DSN="sqlite:…" php -S 127.0.0.1:PORT -t measurement`
  + Playwright. Сервер запускать **в той же команде**, что и тест: между
  вызовами Bash фоновые процессы умирают. Playwright с подменой часов
  (`page.clock`) теряет нажатия на секундомер — тестировать в реальном
  времени.
- Перед пушем всегда `git fetch` + `rebase`: бот журнала изменений и второй
  аккаунт Алекса пушат в main параллельно, push иногда отбивается «cannot lock
  ref» — повторить после rebase.
