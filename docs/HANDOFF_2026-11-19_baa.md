## Как устроена сборка и выкладка (грабли)

- Главная собирается `python3 tools/baa_page/build.py`; правки текста — только
  там, иначе следующая сборка их затрёт. Исключение — `<head>` (title, meta
  description, ld+json): его сборщик берёт из текущего `baa/index.html`,
  поэтому правится прямо в нём.
- Сборка должна быть стабильной: две сборки подряд дают одинаковый файл.
  Новые стили добавлять в `EXTRA` строго ПОСЛЕ строки
  `/* ---- four steps ---- */` — всё после неё сборщик отрезает и вставляет
  заново; стиль до неё задублируется.
- `build.py draft-xxxxxxxxxx` собирает скрытый черновик в `baa/<папка>/`
  (noindex, пути с `../`). Так показывались варианты Алексу. Репозиторий
  публичный — адреса черновиков видны в нём. После решения папку удалить из
  репозитория и добавить в `RETIRED` в `.github/workflows/deploy-baa.yml`:
  выкладка сама ничего не удаляет.
- Выкладка (`deploy-baa.yml`) запускается при пуше в main. FTP (порт 21) с
  GitHub к Beget закрыт с 14.11 — работает запасной путь по SFTP (lftp).
- После перевыпуска сертификата Beget подкладывает заглушку `index.php`
  («Новый сайт успешно создан»), она перекрывает `index.html`; шаг выкладки
  её удаляет.
- Порядок работы: коммит в рабочую ветку → `git merge origin/main` →
  `git push origin HEAD:main` → проверка живого сайта curl'ом, пока
  изменение не появится (обычно 1–3 минуты).
- Read Aloud на странице — iframe с https://playoftime.online/aloud/web/try.html
  (репозиторий `baabroad1-rgb/aloud-reading-assessor`, `web/app/try.html` и
  `try.js`). Высоту iframe сообщает через postMessage `{aloudTryHeight}`.
  Сайт отдаёт .js с кешем на неделю — при каждой правке `try.js` менять
  `?v=` в `try.html`.
- В превью Artifact iframe с чужих сайтов не работают — Read Aloud проверять
  только на живом сайте.
- Хук приватности не даёт писать почту Алекса в командной строке; на
  страницу она вставлена по его прямой просьбе через редактор файла.
